What the Box cannot explain about its own tree — usually something done to it by hand. Nothing here is repaired on its own.

Every scan has its sidecar and every sidecar its scan.

Scans with no sidecar

A file in the tree that nothing describes: put there by hand, or its sidecar was lost. Adopt describes it where it lies. It is not copied and not moved; only its name gains the digest prefix that pairs it with its sidecar.

    Bytes that changed

    The file no longer matches the digest recorded when it was taken in. This may be the first sign of bit rot. Nothing was rewritten: compare it with a backup before doing anything.

      Sidecars with no scan

      A description whose file is gone: moved or removed by hand. Reported only, because it may have been on purpose. Put the file back, or move the sidecar into trash/ yourself.

        Other

          Redraw every thumbnail

          Throws away every stored picture and draws each scan's thumbnail again from its file. Reads every file in the Box. Only the local cache changes; the Box is not written to.

          Verify every byte

          Reads every file in the Box and compares it with its recorded digest — tens of gigabytes over a network filesystem. A mismatch appears above, with both digests, and is never corrected.
