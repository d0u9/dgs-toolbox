    About

    The fields asked for when a PDF of this type is imported.

    Saved to templates/id_card.yaml as written, comments and all.

    What a Template can say

    type
    The file name: lowercase letters, digits, _ and -.
    kind
    document keeps revisions and a HEAD; record is one PDF.
    fields
    What an import asks for, in order. Each has a key and may say:
    required
    An import cannot go on without it.
    distinguishing
    Type and these fields name one Item (documents).
    per_revision
    Kept with each revision and asked again when one is added.
    type
    text (default), date, select, item, country.
    pattern
    A regular expression whose first group suggests a value from the PDF's text.
    patterns
    More of them, for a value written more than one way: tried in order, the first that finds a value fitting the field wins.
    format
    For a country: zh 中国 (default), en China, alpha2 CN, alpha3 CHN.
    options
    For a select: the values to pick from.
    defaults
    Values filled in for a new import.
    ignore_dates
    Dates never suggested, YYYY-MM-DD.
