Templates

    A Template is the fields asked for when a PDF of its type is imported. It is saved as templates/… exactly as written here, comments included.

    What a Template can say 
    type: id_card             # the file name; lowercase, digits, _ and -
kind: document            # document: revisions and HEAD; record: one PDF
fields:
  - key: owner
    required: true
    distinguishing: true  # type + distinguishing fields are unique (documents)
  - key: expires
    per_revision: true    # kept with each revision (documents); asked again when one is added
    type: date            # text (default), date, select, item, country
    pattern: '(\d{4}-\d{2}-\d{2})'  # suggests a value from the PDF's text
  - key: country
    type: country         # cn, CHN, China, 中国 are all kept as one
    format: zh            # zh 中国 (default), en China, alpha2 CN, alpha3 CHN
  - key: status
    type: select
    options: [current, expired]
defaults: {}              # a value filled in for a new import
ignore_dates: []          # dates never suggested, YYYY-MM-DD
